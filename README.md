# 🎵 About

**TuneVerse** is a browser-based music player built using **HTML5, CSS3, Vanilla JavaScript, and JSON**.

The project provides a dedicated music-listening interface where users can browse tracks, search through the available music collection, select songs, and control playback directly from the browser.

TuneVerse focuses on creating a modern and visually engaging music experience while keeping the implementation lightweight and based on native web technologies.

The project contains local audio resources, music artwork, structured track information, and frontend logic required to create the music-player experience.

# 💭 The Idea

Music applications are often built around large backend systems, streaming services, APIs, recommendation engines, and complex infrastructure.

TuneVerse takes a simpler approach.
